SEB Heavy Resource Stress

اختبار استقرار عالي الكثافة للمعالج ومصفوفات الذاكرة الموزعة داخل الحاوية المعزولة.

ملاحظة معمارية: متصفحات الويب (بما فيها محرك SEB) تضع حداً أقصى لذاكرة التبويب الواحد يتراوح عادة بين 2GB إلى 4GB. الاختبار هنا يستخدم تقنية Multi-Worker Memory Allocator لدفع تخصيص الذاكرة عبر خيوط معالجة متوازية قدر الإمكان لاختبار ثبات بيئة المتصفح دون كسر قيود النظام المعماري فجأة.

اختبار الذاكرة المكثف (Multi-Threaded RAM)

خامل

يخصص كتل بحجم 500MB لكل Thread متوازي لرفع سعة الاختبار إلى أقصى حد متاح لمحرك المتصفح.

اختبار المعالج المكثف (Full Cores Stress)

خامل

تشغيل جميع المسارات المنطقية (All Hardware Threads) بحسابات مصفوفات معقدة ومستمرة.
